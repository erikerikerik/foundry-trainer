# Foundry Trainer

A native Rust, browser-based LoRA trainer for image-generation models. Local-first, no Python at runtime.

Status: pre-alpha, specification stage. See `STATUS.md` for progress and `docs/SPEC.md` for the full specification.

Planned workflow: Dataset, Caption, Configure, Output, Train, Review.

Installation and usage instructions will land here once Phase 1 produces a runnable build.
